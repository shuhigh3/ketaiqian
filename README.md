# 课态签（ketaiqian）

一款大学生自用辅助应用：课表查询与上课提醒、按课表自动修改微信状态、每晚自动查寝签到、
学习通与知到的自动刷课。**只在本人手机上运行**，课表、登录态与账号不上传任何服务器。

- 下载页（推荐从这里开始）：<https://shuhigh3.github.io/ketaiqian/>
- 最新版本：<https://github.com/shuhigh3/ketaiqian/releases/latest>
- 当前版本：**1.16.14**（versionCode 60，Android 8.0+）

## 它做什么

| 能力 | 说明 |
| --- | --- |
| 课表与提醒 | 导入教务表格或手动添加；上课前按节次提醒，首页「今日概览」逐门课显示进行中 / 即将开始 / 已结束 |
| 微信状态 | 到点自动把主微信（含分身）状态改成「课程名 课中」，下课后收尾；失败会留在状态条与日志里 |
| 查寝代签 | 填好学校全称、学号与密码（可选手机动态码登录），每晚到点自动拉任务、带定位与照片提交；**登录一次后会话存本机，重启不用再等短信动态码** |
| 刷课托管 | 学习通在悬浮窗里跑、知到在后台线程跑，两个平台可同时进行；刷题/作业需自备 DeepSeek Key |
| 检查更新 | **进入应用即自动检查**（同时读 Pages / jsDelivr / raw 三处清单，取最高版本号），发现新版本弹窗提示「立即更新 / 稍后」，同一版本每次运行只提示一次；手动入口仍然保留 |

首页刷课、查寝、远程三张卡**默认收缩**，只显示一个状态点与名称，点「展开」才看详情与操作：

- 绿点 = 进行中 · 灰点 = 未设置 · 红点 = 离线 · 黄点 = 状态异常

## 安装

1. 从 [Releases](https://github.com/shuhigh3/ketaiqian/releases/latest) 下载 `ketai-<版本号>.apk`；
2. 首次安装需要在系统里给「课态签」打开「安装未知应用 / 允许来自此来源」；
3. 打开后按提示授予通知、定位与电池优化白名单。

从 1.16.1 起使用固定签名（同一把 keystore），之后的版本可以直接覆盖安装，课表、登录态与设置都保留；
早期 debug 签名包与本包签名不同，只能卸载重装一次。

## 使用说明

1. **导入课表**：右上角「导入课表」，或右下角 + 手动添加；设置里确认开课周与节次时间。
2. **改微信状态**：设置 → 微信状态文案，写模板（`{course}` 会替换成课程名），勾选自动改状态。
3. **查寝**：底部「查寝」填学校全称、学号、密码与签到点，保存后点「登录并查看任务」；需要验证码时用手机动态码登录一次，之后会话存在应用私有目录（`jrxy_session.json`），重启 App 会先拿它直连业务接口，通了就不再走登录页；点「退出登录」或换账号会自动清掉这份会话。
4. **刷课**：底部「刷课」进分流页，学习通与知到各自登录、选课程后「开始托管」；学习通需要悬浮窗权限。
5. **检查更新**：正常不用管——每次进入应用会自动查一次并弹窗提示；想手动确认时右上角三点 → 检查更新，默认地址已预填（填自定义地址会记住）。

## 版本清单与更新地址

- 默认（GitHub Pages，应用内已预填）：
  `https://shuhigh3.github.io/ketaiqian/version.json`
- 备选镜像（自动检查会一起读）：
  `https://fastly.jsdelivr.net/gh/shuhigh3/ketaiqian@main/version.json`
  `https://raw.githubusercontent.com/shuhigh3/ketaiqian/main/version.json`

> 实测提醒：jsDelivr 的 `@main` 会被缓存拖在旧提交（仓库已是 51 时它仍返回 47），
> 所以默认走 Pages，并让应用同时读三处取最高版本号；发版后若某镜像滞后，不影响发现新版本。

清单格式：

```json
{
  "versionCode": 60,
  "versionName": "1.16.14",
  "apkUrl": "https://github.com/shuhigh3/ketaiqian/releases/download/v1.16.14/ketai-1.16.14.apk",
  "notes": "换新图标：白色课表格+对勾，靛蓝→紫渐变底，补 Android 13 单色主题图标"
}
```

## 边界与风险

- 只支持 Android 8.0 及以上，没有 iOS 版本；
- 微信、今日校园、学习通改版或风控调整都可能让自动动作失效，失败会显示出来，不会假装成功；
- 查寝密码明文存放在应用私有目录，用于夜间自动登录；课表与登录态不上传，但也没有云端备份；
- 用脚本代替人工学习或签到可能违反校规与平台协议，请只在自己的账号上使用，风险自负。
